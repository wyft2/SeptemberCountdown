# 九月倒计时

Windows 桌面无边框液态玻璃倒计时，支持数字流光、透明玻璃数字、数字流沙，以及检查更新。

## 下载

请到 [Releases](https://github.com/wyft2/SeptemberCountdown/releases/latest) 下载最新的 Windows 版本。

## 检查更新

程序会从本仓库读取 `version.json`：

```json
{
  "version": "1.6.0",
  "url": "https://github.com/wyft2/SeptemberCountdown/releases/latest",
  "page": "https://github.com/wyft2/SeptemberCountdown",
  "notes": "更新说明"
}
```

国内网络下，程序会自动尝试 GitHub、jsDelivr、Fastly、国内 GitHub 镜像、Gitee 和 GitHub Pages；也可以在设置里填写自定义更新源。
