九月倒计时  v1.7
Windows 桌面液态玻璃倒计时
作者：九月  ·  powered by 九月
============================================================

一个不用安装、双击就能用的桌面倒计时小工具。

【v1.7 更新】
· 透明玻璃数字与数字流沙改为互斥：开启一个会自动关闭另一个；
· 新增樱花、熔岩、森林、星云四套配色，共八套；
· 数字流光开启后出现“颜色渐变”子菜单，开启后多种颜色沿随机方向流动，替换单色流光；
· 新增星空模式：可自定义待机时间，系统无操作达到时间后，倒计时平移进入全屏银河星空，
  伴随随机星尘和流星粒子，点击任意位置退出；
· 设置页新增“预览星空”，不用等待待机时间也能查看效果。

【v1.6 更新】
· 新增“检查更新”：设置页、右键菜单、托盘菜单都能打开；
· 国内网络会自动尝试 GitHub、jsDelivr、Fastly、国内 GitHub 镜像、Gitee 等多个更新源；
· 支持自定义更新源，远程都不可用时读取程序目录下的 version.json 作为离线回退；
· 发现新版本会显示版本号、更新说明和下载页按钮，不会自动下载安装。

【v1.5 更新】
· 新增“数字流沙”：数字内部填充流动的金色沙粒与渐变，类似手环“流沙”表盘；
· 流沙、流光、玻璃数字可以独立开关，也可以叠加使用；
· 版本号更新为 v1.5，彩蛋触发方式不变。

【v1.4 更新】
· 液态玻璃改为无边框：去掉卡片边框和多余装饰，只保留倒计时主体；
· 修复窗口位置记忆：拖动后关闭，重新启动会回到上次关闭前的位置；
· 新增“数字流光”：数字填充彩色渐变，并有流光扫过，可在设置中开关；
· 新增“透明玻璃数字”：数字呈透明玻璃圆柱体，带高光、边缘反光和折射感；
· 设置页版本号连续点击 7 次，会提示“已进入彩蛋模式”，随后出现彩蛋菜单；
· 彩蛋菜单包含“作者主页”和“烧脑时刻”两个入口。

【显示效果】
设置 → 显示效果，可选择：
· 液态玻璃：无边框的亚克力玻璃背景，只显示倒计时主体。
· 液态透明：去掉卡片和边框，只保留倒计时；背后带一层柔和流动光晕。
· 纯透明：连光晕也不要，只留倒计时文字浮在桌面上。

三种模式都会隐藏顶部栏、按钮、底栏、状态和进度，只保留倒计时主体。
拖动倒计时区域可以移动窗口；双击倒计时打开设置；右键倒计时打开菜单
（设置 / 桌面置顶 / 退出）。

【数字效果】
设置 → 数字效果：
· 数字流光：数字填充渐变，并有一道流光扫过，颜色跟随当前配色。
  开启后会出现子菜单“颜色渐变”：开启后多种颜色沿随机方向流动，
  替换原来的单色流光效果。
· 透明玻璃数字：数字显示为透明玻璃圆柱体，带顶部和底部高光、边缘反光
  和中间的镜面高光带。
· 数字流沙：数字内部填充流动的金色沙粒、细沙纹理和缓慢下落的渐变，
  类似小米手环“流沙”表盘的流动质感。
· 流光可以和玻璃/流沙叠加；透明玻璃数字与数字流沙互斥，
  开启一个会自动关闭另一个。
· 默认关闭；开启后会立即预览，点“保存”后生效。

【星空模式】
设置 → 星空模式：
· 打开“开启星空模式”，再设置“待机时间”（1-120 分钟）；
· 当系统无鼠标/键盘操作达到待机时间后，倒计时会从当前位置平移进入
  全屏银河星空，背景有随机星尘、闪烁星星和流星粒子；
· 点击任意位置、按 Esc、空格或回车退出，回到原来的倒计时窗口；
· 不会修改目标时间，也不会影响倒计时计算；
· 设置里的“预览星空”可以立即进入，不用等待待机时间。

【彩蛋模式】
在设置页底部找到版本号“九月倒计时 v1.7”，连续点击 7 次
（每次间隔不要超过约 1.3 秒），会提示“已进入彩蛋模式”，随后出现彩蛋菜单：
· 作者主页：打开 https://github.com/wyft2
· 烧脑时刻：打开 https://wyft2.github.io/Echo-Layer-Page-7/
点击菜单外的空白处、右上角关闭按钮或按 Esc 可退出彩蛋菜单。

【检查更新】
设置页底部点“检查更新”，右键倒计时菜单和托盘菜单里也有入口。
· 默认会并行尝试 GitHub、jsDelivr、Fastly、gh-proxy 国内代理、Gitee 和 GitHub Pages；
· 国内网络访问 GitHub 不稳定时，可以在设置里“自定义更新源”填写可访问的 version.json 地址；
· 远程更新源都失败时，会读取程序目录下的 version.json 作为离线回退；
· 发现新版本会显示版本号、更新说明和下载页按钮，不会自动下载或安装；
· 检查更新只读取很小的文本文件，不会上传任何本机信息。

version.json 格式（放在 GitHub/Gitee 仓库或任意静态网页即可）：
{
  "version": "1.7.0",
  "url": "https://cdn.jsdelivr.net/gh/wyft2/SeptemberCountdown@main/download/SeptemberCountdown_v1.7.0_Windows.zip",
  "page": "https://github.com/wyft2/SeptemberCountdown/releases/latest",
  "notes": "更新说明"
}
也可以写成一行纯文本：1.6.0 https://下载页

默认更新源（程序会并行尝试）：
https://raw.githubusercontent.com/wyft2/SeptemberCountdown/main/version.json
https://cdn.jsdelivr.net/gh/wyft2/SeptemberCountdown@main/version.json
https://wyft2.github.io/SeptemberCountdown/version.json
国内镜像会自动尝试 jsDelivr、Fastly、gh-proxy.com 和 Gitee；
下载会优先使用 jsDelivr 上的 Windows 包，避免 GitHub Releases 在国内访问困难。

【开机自启动】
设置 → 窗口行为 → 打开“开机自启动”，登录 Windows 后会自动启动九月倒计时。
· 不需要管理员权限；
· 启动项写入当前用户：
  HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run
  值名称：SeptemberCountdown
· 关闭开关后会自动移除该启动项；
· 开机自启动默认关闭；
· 如果以后移动了 exe 的位置，启动一次程序会自动更新启动项路径。
· 执行 九月倒计时.exe --reset 也会同时移除启动项。

【功能】
· 自定义倒计时文本（最多 40 个字符）
· 自定义目标日期与时间
· 无边框液态玻璃 / 液态透明 / 纯透明三种显示效果
· 数字流光（含颜色渐变子菜单）、透明玻璃数字、数字流沙三种数字效果
  （玻璃与流沙互斥，其余可叠加）
· 星空模式：自定义待机时间，全屏银河星空与随机粒子
· 八套配色：极光 / 深海 / 落日 / 薄荷 / 樱花 / 熔岩 / 森林 / 星云
· 设置界面可开启或取消“桌面置顶”
· 可选择显示或隐藏秒数
· 开机自启动（可随时关闭）
· 自动记住窗口位置和设置
· 最小化到系统托盘；到时间后显示“时间到”
· 检查更新（多源、国内镜像、自定义更新源）
· 彩蛋模式：连续点击版本号 7 次触发
· 作者署名 “powered by 九月” 显示在文件属性中

【使用】
1. 双击“九月倒计时.exe”启动。
2. 拖动倒计时区域移动；双击倒计时打开设置；右键倒计时打开菜单。
3. 修改文本、日期、时间、显示效果、数字效果，点“保存”生效。
4. 右键菜单或托盘菜单都可以切换“桌面置顶”。
5. 透明模式下没有常驻按钮，退出方式：
   · 右键倒计时 → 退出九月倒计时；
   · 右键系统托盘里的九月图标 → 退出；
   · 或右键任务栏图标 → 关闭窗口。
   托盘图标双击可以召回窗口，右键菜单也可以打开设置或切换置顶。

【设置在哪里】
%LOCALAPPDATA%\SeptemberCountdown\settings.json

想恢复出厂设置：
· 删除上面的 settings.json 后重新启动；或
· 在命令提示符中运行：
  九月倒计时.exe --reset
  （同时会关闭开机自启动）

【系统要求】
Windows 10 / 11（64 位）
.NET Framework 4.8（Windows 10 1903+ 与 Windows 11 已内置，无需另外安装）
平时无需联网，只有“检查更新”需要网络；无外部运行库。

【小提示】
· 液态玻璃使用 Windows 亚克力模糊，实际效果会随桌面壁纸变化。
· 液态透明 / 纯透明使用逐像素透明窗口，不会给桌面加一层底色。
· 如果系统“透明效果”关闭，或远程桌面/虚拟机不支持亚克力，
  仍会保留液态配色和光晕。
· 如遇到模糊/闪烁等显示问题，可用以下参数启动，关闭系统亚克力：
  九月倒计时.exe --no-acrylic
  （此时液态玻璃会自动使用透明渲染，不会出现黑色底块）
